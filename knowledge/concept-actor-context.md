# Actor context

Broker can set up customers, save drafts, request quotes and issue acceptable quotes. Senior underwriter reviews referred quotes and attaches suitable survey evidence.

An actor container encloses ordered actions. A location scope encloses configuration changes. Moving a location modifier into an actor's action sequence is invalid because it no longer identifies a configuration target.

Logical references cross role boundaries. Approval must reference the specific quote request and policy created earlier, never the latest quote on screen.
